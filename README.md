### Party Manager

Party Manager is a lightweight PHP 8 application for managing event food and drink packages.

It allows users to place reservations, select beverages for each package, and track orders. The administration area provides tools to manage bookings, payments, quantities, and package assignments through a simple and intuitive interface.

## Features

- Package booking management
- Beverage selection per package
- Order tracking
- Payment status management
- Administrative dashboard
- MySQL database support
- Modern PHP 8 codebase with PDO

## Requirements

- PHP 8+
- MySQL / MariaDB
- Composer
